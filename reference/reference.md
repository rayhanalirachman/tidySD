# Normalising reference values

Identical to \[constant()\] in behaviour; the separate name records that
the value is a normalising reference rather than a policy lever, and it
is reported as such by \`print()\`.

## Usage

``` r
reference(...)
```

## Arguments

- ...:

  Named numeric values.

## Value

An \`sd_element\` to be passed to \[sd_parameters()\].
