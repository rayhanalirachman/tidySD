# Plot a model diagram

A deliberately plain layered layout: stocks on the spine, everything
else arranged around them. It is meant for reading a model, not for
publication.

## Usage

``` r
# S3 method for class 'sd_diagram'
autoplot(object, ...)

# S3 method for class 'sd_diagram'
plot(x, ...)
```

## Arguments

- object:

  An \[sd_diagram()\].

- ...:

  Unused.

- x:

  An \[sd_diagram()\].

## Value

A \`ggplot\` object.
