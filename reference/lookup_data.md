# Points for a graphical (lookup) function

Points for a graphical (lookup) function

## Usage

``` r
lookup_data(name, x, y)
```

## Arguments

- name:

  Name of the \[lookup()\] these points belong to.

- x, y:

  Numeric vectors of equal length, \`x\` strictly increasing.

## Value

An \`sd_element\` to be passed to \[sd_parameters()\].
